# Book & book-chapter cover images

Drop cover images for the **Publications** page here. Each file is referenced by
the `cover:` field of an entry in [`data/publications.js`](../../../data/publications.js).

- Use the exact kebab-case filenames listed as `cover:` in `publications.js`
  (e.g. `psycho-educational-assessments.jpg`).
- JPG or PNG both work. Portrait book-cover proportions look best.
- Book chapters show the cover of the **book they appear in**; several chapters
  can share the same filename and the cover appears once in the gallery.
- If a file is missing, its cover is simply skipped — no broken image — so you
  can add covers one at a time.

Recommended: ~600 px wide, optimized for web.
