Software

Open-source R packages, interactive Shiny applications, and R functions for psychometrics, item response theory, and educational data analysis.

R Packages

Published on CRAN

eirm

Explanatory item response modeling for dichotomous and polytomous item responses. Estimate explanatory extensions of Rasch models with a simple, unified interface.

CRAN GitHub Documentation

profileR

Profile analysis of multivariate data in R — within-person and between-person profile reliability, criterion-related profile analysis, and profile analysis via multidimensional scaling. With Christopher D. Desjardins.

CRAN Documentation

hemp

Companion package to the Handbook of Educational Measurement and Psychometrics Using R (CRC Press) — data sets and functions used throughout the book. With Christopher D. Desjardins.

GitHub Book
Shiny Applications

Interactive tools for teaching & learning

Web applications built with R Shiny for exploring psychometric concepts hands-on.

Exploratory Factor Analysis

Run and visualize exploratory factor analysis interactively — extraction methods, rotation, and factor loadings.

Sampling Distributions

Simulate sampling distributions to build intuition for standard errors and the central limit theorem.

IRT Model Explorer

Explore item response models interactively — the Graded Response, Partial Credit, and Nominal Response models.

R functions & teaching materials

I also share standalone R functions for ability estimation (EAP, MAP, and MLE), data simulation for IRT models, and Monte Carlo simulation studies, along with workshop materials and tutorials on data mining and psychometric modeling in R. Find them on my GitHub profile and my blog at okan.cloud.
